# ShopHub. | Premium E-Commerce Platform

ShopHub is a full-stack, enterprise-grade luxury e-commerce platform built with modern web technologies. It features a sleek, magazine-style UI, real-time database syncing, and a seamless checkout experience designed to rival top international fashion brands.

## 🌟 Key Features

- **Premium UI/UX:** Luxury aesthetic with custom scrollbars, minimal magnetic buttons, and glassmorphism quick-view modals.
- **Animated Mega Menu:** Smooth, multi-column editorial navigation powered by Framer Motion.
- **Real-Time Database:** Live customer reviews, dynamic rating calculations, and instant product syncing using Supabase.
- **Fully Responsive:** Flawless experience across desktop, tablet, and mobile devices featuring a custom mobile sidebar.
- **Authentication & Security:** Secure user login/registration and protected order history.
- **Smart Cart & Wishlist:** Persistent local/database storage for saved items and cart management.

## 🛠 Tech Stack

- **Framework:** [Next.js (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Database & Auth:** [Supabase](https://supabase.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Notifications:** [React Hot Toast](https://react-hot-toast.com/)
